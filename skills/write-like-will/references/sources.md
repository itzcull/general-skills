# Sources

This file records the evidence for this skill. It comes from one working session on 2026-11-01. The samples are paraphrased and generalised. This repository is public, so it holds no verbatim messages, client names, or colleague names.

## S1 — Observed messages

Will's own messages in internal chat and PR reviews, read during the session.

Chat register:

- Long single-sentence plans: "given you say I'm blocked by <work>, I'm just going to propose <thing>, get a casual sign-off from you, and continue with the rest".
- Short everyday words: "probs", "kinda", "ok", "plz".
- Lowercase sentence starts, mixed with normal capitals.
- Self-correction in the next message: "oh sorry, it was a document I created, that theirs referenced".
- Holding a position politely: "I'd still like to emphasise <point>, whether or not we call it <name>".
- Light nudges: offering `:+1:` reactions as answer options, then "react plz"; "I saw you type, then stopped".

Review register:

- A PR review that opens "Sup," then "It's strong work", then "A few fixes before it goes to <client>:".
- Fixes grouped under short bold labels (for example "Remove or source", "Evidence", "Rules", "Design"), each one concrete with a number or source.
- A closing line that discloses AI help: "Claude helped me".

Used for: the registers, the chat traits, and the review shape.

## S2 — Stated preferences

What Will asked for, or chose, in the same session.

- He asked for a status message that names each blocker, links the evidence for it, and gives the fix for each one.
- He was shown a formal version (bold headings, "Evidence:" and "Unblocker:" labels) and a casual version (lowercase, one plain line per problem, an arrow to the ask, a "tl;dr" list of asks). He chose the casual version for an internal thread.
- His standing instructions require links to sources for factual claims, and Simplified Technical English for formal writing.

Used for: evidence links, problem-and-fix pairing, the chat default for internal threads, and the formal register boundary.
